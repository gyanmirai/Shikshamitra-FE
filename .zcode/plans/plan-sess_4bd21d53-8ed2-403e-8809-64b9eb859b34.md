## Goal
Bring `RoomAvailabilityTable.tsx`, `RoomReservationsTab.tsx`, and `RoomApprovalQueue.tsx` in line with the `shikshamitra-ui-components` skill (customizable tables, `ThreeDotsActions`, `CustomDialog`, tab-based status filters, `Label` counts, `DD-MM-YYYY` dates, `size="small"`). Scope is limited to these 3 files; the parent `RoomAvailabilityScreen.tsx` keeps its current props/signature.

## Decision (stated, not asked)
- Keep the shared domain chips `RoomStatusChip`, `ApprovalStatusChip`, `ConflictSeverityChip` (used in drawers/details; render `Chip variant="soft"` ≈ `Label`). Only the standalone `reservationType` cell becomes a `Label`.
- Loading/concurrency: approve/reject/cancel open modal dialogs, so the in-flight spinner moves onto the dialog action `LoadingButton` (bound to `pendingAction`); action menu items are `disabled` while `isAnyActionPending`.

## File 1 — `RoomAvailabilityTable.tsx`
1. **Actions column → `ThreeDotsActions`**
   - `showViewIcon` → calls `onViewRoom(row.roomId)` (replaces the raw eye `IconButton`).
   - `actions` render-prop returns a `<MenuList>` of conditional `<MenuItem>`s (each calls `popover.onClose()` then the handler), matching the `scheduleExamTable` pattern:
     - **Reserve Room** — `canReserve`; disabled when `row.status === 'maintenance'` (keep the "blocked" tooltip text as the item's `Tooltip`/`disabled` reasoning).
     - **View Schedule** — wires the currently-unused `onViewSchedule(row.roomId)` prop.
     - **Mark Maintenance** — `canMaintenance`; wires the currently-unused `onMarkMaintenance(row)` prop.
     - **View Approval** — `canApprove && row.status === 'pendingApproval'` → `onCancelReservation(row)` (keep existing semantics).
2. **Status column → right-sticky**: add `stickyPosition: 'right'`, keep `minWidth` ≥ 120, keep `RoomStatusChip` render.
3. Remove now-unused `Tooltip`, `IconButton`, raw `Iconify`-in-button JSX; keep `FacilityIcons`, `GlobalIcons.eye`.
4. Add `'use client'` already present — keep.

## File 2 — `RoomReservationsTab.tsx`
1. **Replace the 7-card status filter grid with a `<Tabs>` + `<Label>` bar** (skill §2.9.5), `variant="scrollable" scrollButtons="auto"`:
   - Tabs: All / Active / Pending / Approved / Completed / Cancelled / Rejected.
   - Each tab label = `<Box>{label} <Label color={...}>{count}</Label></Box>`; counts derived from `reservations`.
   - `value={filter}` → `setFilter` (keeps existing client-side `filtered` memo).
2. **Actions column → `ThreeDotsActions`**
   - `showViewIcon` → `onViewRoom(row.roomId)`.
   - `actions` MenuList: Edit (`onEdit` && draft/pendingApproval), Approve (`canApprove` && approvalStatus==='pending'), Reject (same condition), Cancel Reservation (`onCancel` && active/approved/pendingApproval). Items `disabled` when `isAnyActionPending` (and not the in-flight row).
3. **Approval column → right-sticky**: `stickyPosition: 'right'`, minWidth ≥ 120.
4. **`reservationType` cell**: `Chip` → `<Label variant="soft" color="default" sx={{ textTransform: 'capitalize' }}>`.
5. **Date cells**: `DD/MM/YYYY` → `DD-MM-YYYY` (both the date range and recurring-until renders).
6. **Reject dialog → `CustomDialog` + `DialogScrollContent`**
   - `title` = icon + "Reject Reservation" + `CustomTooltip` info (skill §2.3 dialog-title-info pattern).
   - Body: keep `Alert` + `TextField` (`size="small"`).
   - Footer `DialogActions`: `Button size="small" outlined` Cancel + `LoadingButton size="small" color="error" loading={isRejecting}` Confirm Rejection.
7. **Cancel & Approve `ConfirmDialog`s**: action buttons get `size="small"`; Approve action becomes a `LoadingButton loading={isBusy(approveId,'approve')}`.
8. Drop unused imports (`alpha`, `Dialog`, `DialogTitle`, ... ) after the swap.
